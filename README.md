This is my first attempt at building a C compiler. I don’t have a specific target version in mind yet, for now I’m focusing on the compiled code for the Intel x86-64 architecture. I’m well aware I’m still far from the machine‑code generation stage. For the moment, this README will be a bit “dead” until I make real progress, at which point I’ll update it. I intend to build everything from scratch, including the lexical analyzer and the parser, without using tools like Flex or Yacc/Lex.

All the resources I’m using for this project are:
- Compilers: Principles, Techniques, and Tools
- Engineering a Compiler
- Introduction to Automata Theory, Languages, and Computation.
- Low-Level Programming: C, Assembly, and Program Execution on Intel 64 Architecture
